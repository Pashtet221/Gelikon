# Промпт для WordPress Bridge: заполнение ACF страницы «О компании»

Скопируйте весь блок ниже в Codex, подключённый к сайту через WordPress Bridge.
Промпт сохраняет уже показанные шаблоном тексты в ACF-полях самой страницы
`/about/`. После выполнения значения можно менять в обычном редакторе WordPress.

```text
Работай с production-сайтом через WordPress Bridge. Не изменяй файлы темы и не
добавляй значения по умолчанию в PHP. Найди WordPress-страницу по адресу
`/about/` и заполни её ACF-поля теми значениями, которые сейчас выводит шаблон
страницы «О компании» как fallback.

Сначала выполни безопасную проверку: страница существует, её ID ненулевой,
активна функция ACF `update_field`. Если любая проверка не пройдена — ничего не
записывай и сообщи об ошибке. Затем через WP-CLI WordPress Bridge выполни эту
команду из корня установки WordPress:

wp eval '
$page_id = url_to_postid(home_url("/about/"));
if (!$page_id) {
    $page = get_page_by_path("about", OBJECT, "page");
    $page_id = $page ? (int) $page->ID : 0;
}
if (!$page_id) {
    WP_CLI::error("Страница /about/ не найдена; изменения не внесены.");
}
if (!function_exists("update_field")) {
    WP_CLI::error("ACF update_field() недоступна; изменения не внесены.");
}

$fields = [
    "field_about_hero_title" => "Gelikon Line",
    "field_about_hero_subtitle" => "Технологии для жизни и здоровья",
    "field_about_intro_text" => "Gelikon Line работает на рынке электроники и радиотехнического оборудования с 2001 года, развивая продуктовые направления для дома, связи и персонального здоровья.",
    "field_about_history_title" => "История и опыт",
    "field_about_history_text" => "С первых лет работы мы участвовали в становлении рынка видеорегистраторов и электроники, выстраивая процессы контроля качества и сервисной поддержки.",
    "field_about_approach_items" => [
        ["icon" => "", "title" => "Отбор на выставках", "description" => "Выбираем перспективные решения и партнеров по реальному качеству продукции."],
        ["icon" => "", "title" => "Тестирование", "description" => "Проверяем устройства в рабочих сценариях до вывода в продажи."],
        ["icon" => "", "title" => "Адаптация", "description" => "Локализуем, адаптируем документацию и пользовательский опыт для рынка РФ."],
        ["icon" => "", "title" => "Контроль производства", "description" => "Сопровождаем партии и контролируем стабильность поставок и характеристик."],
    ],
    "field_about_production_text" => "Продукция Gelikon Line производится на крупных современных фабриках с выстроенными системами контроля и технологической дисциплины.",
    "field_about_clients_text" => "За годы работы Gelikon Line сотрудничала с крупными коммерческими и розничными партнерами, подтверждая репутацию стабильного поставщика.",
    "field_about_warranty_text" => "Мы несем гарантийные обязательства по всей поставляемой продукции и обеспечиваем поддержку по сервисным вопросам.",
    "field_about_brand_text" => "В 2022 году был зарегистрирован товарный знак Gelikon Line (№ 884837), что закрепило развитие бренда на рынке.",
];

foreach ($fields as $field_key => $value) {
    if (!update_field($field_key, $value, $page_id)) {
        WP_CLI::warning("Поле {$field_key}: значение не изменилось или не было записано.");
    }
}

clean_post_cache($page_id);
WP_CLI::success("ACF-поля страницы /about/ (ID {$page_id}) заполнены.");
'

Не трогай медиа-поля `hero_background`, `history_image`, `production_image`,
`clients_logos` и вложенные `icon`: в шаблоне для них нет готовых файлов, поэтому
выдумывать ID вложений нельзя. Не перезаписывай заголовок страницы, slug, статус,
контент Gutenberg и шаблон страницы.

После записи прочитай каждое заполненное поле через ACF, покажи ID и URL страницы,
а также короткий отчёт «ключ поля → сохранённое значение». Отдельно подтверди,
что значения теперь хранятся в данных страницы и отображаются в блоке
«О компании — контент страницы» в админке, а не берутся из fallback в PHP.
```

Команда использует **ключи ACF**, а не только имена полей. Это позволяет ACF
создать служебные ссылки `_имя_поля → field_...`, благодаря которым сохранённые
значения корректно появляются в редакторе страницы WordPress.
